# ESS 배터리 수명 예측

목적: ESS(에너지 저장 시스템) 배터리가 수명(SOH 80%, 0.88Ah)에 도달하기까지의 총 사이클 수 `cycle_life`를 **초기 100 cycle 데이터만으로** 예측해, 교체 시점을 미리 계획할 수 있게 한다. (교체 비용은 ESS CAPEX의 30~40%가 될 것이다.)

## 프로젝트 개요
- 데이터셋 : MIT-Stanford Battery Dataset (Severson et al., Nature Energy 2019)
- 학습 데이터 : Batch 1 (2017-05-12)
- 평가 데이터 : Batch 2 (2018-02-20), 추가 평가 Batch 3 (2018-04-12)
- 태스크 : **Regression** (Cycle Life 예측)  ← Regression / Classification 택1
- Target Data : `cycle_life` (EOL = 용량이 처음의 80%인 0.88Ah에 도달할 때까지의 사이클 수), 모델은 `log10(cycle_life)`를 예측하고 MAPE는 사이클 수로 되돌려 계산
- 사용 셀 : 139셀 중 Target 값이 정의에 맞는 **119셀** (B1 36 · B2 39 · B3 44)
  - 제외 20셀: EOL 미도달 10셀(B1) · Target 값 없음 10셀(B2 8, B3 2)

## EDA

- **Cycle Life 분포**
  - 평균 수명 B1 788 · B2 566 · B3 1,060 cycle (전체 392~1,935). 장수명(>1,000) 26%, 단수명(<500) 24%(전부 B2).
  - 핵심 발견 : **배치마다 수명 분포가 다르다.** 또, B2의 이상치 9셀은 측정 오류가 아니라 셀 구조가 다른(newstructure) 하위집단이다.

- **열화 곡선 분석**
  - 장수명 vs 단수명 셀의 열화 속도 차이 : 모든 셀이 완만하게 줄다가 어느 지점(knee)부터 급격히 빨라진다. 
  단수명(<500, 28셀)은 knee 이전 열화 속도가 장수명(>1,000, 31셀)의 약 2.3배(1.33 vs 0.57 ×10⁻⁴ Ah/cycle), knee 이후는 약 2.4배(13.7 vs 5.8)로 더 빠르다. knee 이후 열화 속도와 수명의 Spearman ρ = −0.83.
  - Knee point 존재 여부 및 발생 시점 : 두 직선 piecewise 적합으로 셀마다 knee를 찾았고 **모든 셀에 존재**한다(knee 이후 중앙값 약 10.4배 가속). 발생 시점은 수명의 약 77%(59~87%)이며 단수명 셀은 수명 중앙값 450의 약 73%(333 cycle), 장수명 셀은 1,115의 약 79%(905 cycle)에서 시작한다. 가장 이른 knee도 245 cycle이다.
  - 초기 100 cycle : 용량이 거의 그대로다(QD(cycle 100) / QD(cycle 2) 중앙값 1.002, 최대 변화 2.1%). QD(100)이 QD(2)보다 큰 셀이 B1 89% · B2 64% · B3 84%이다.
  - 핵심 발견 : knee 시점과 수명의 Spearman ρ = 0.99로, 수명은 사실상 knee가 언제 오느냐로 정해진다. 그런데 knee는 가장 이른 셀도 245 cycle이라 cycle 100에는 보이지 않으므로 **용량 곡선만으로는 초기에 수명을 알 수 없다.**

- **ΔQ(V) 곡선 분석**
  - Cycle 100 − Cycle 10 방전 곡선 차이의 골이 단수명 셀에서 깊다(예: 수명 534 셀 −0.063Ah vs 수명 1,074 셀 −0.025Ah).
  - 핵심 발견 : **log Var ΔQ와 log 수명의 Spearman ρ = −0.89** (배치별 −0.71 ~ −0.83). 셀 구조가 달라도 같은 직선 위에 놓인다.

- **충전 속도(C-rate)와 수명의 관계**
  - 같은 충전방식에서도 셀 구조에 따라 수명이 약 2배 차이난다(B2 기존 구조 448~484 vs newstructure 872~991).
  - 핵심 발견 : “고속 충전 = 단명”은 같은 셀 구조 안에서만 성립한다. 충전방식 변수는 배치마다 집합이 달라 입력에서 제외.

- **추가 확인한 내용**
  - **원논문의 학습/테스트 분할** : 원논문 코드([`LoadData.m` 97~104행](https://github.com/rdbraatz/data-driven-prediction-of-battery-cycle-life-before-capacity-degradation/blob/master/LoadData.m#L97-L104))는 
  Batch 1(41셀)과 Batch 2(43셀)를 한 줄로 이어 붙여 번갈아 학습 41셀 · 테스트 43셀로 나눈다. 
  즉 **학습에 Batch 1·2 셀이 섞여 있다.** 이 과제처럼 Batch 1만 학습해 Batch 2를 맞히는 방식이 아니다.
  - **EOL 미도달 셀 제외** : 실험이 끝나기 전에 측정이 멈춘 셀(B1 10셀)은 Target 값이 실제보다 짧게 기록돼 제외했다. 포함하면 온도–수명 상관이 −0.48, 제외하면 −0.17이다. 정상 셀 중 수명 상위 10개와 하위 10개의 평균 온도 차도 0.5°C뿐이라 온도는 수명을 정하는 신호가 아니다.
  - **전처리 처리 건수** : cycle 1 더미 제거(B1 36셀), 용량 스파이크 보간 11건(B1 1 · B2 8 · B3 2), IR 0 기록 6셀(B2) 결측 처리, 충전시간 이상값은 평균 대신 중앙값 사용.
  - **ΔQ(V) 노이즈** : 14셀(B1 10 · B2 2 · B3 2)에서 방전 곡선의 평탄 구간(전압 0.01V 변화에 용량 약 0.026Ah)이 전압 측정 오차를 부풀려 지글거린다. 곡선을 매끄럽게 펴도 핵심 피처 차이가 최대 0.06이고 수명 상관은 그대로(−0.826 → −0.825)라 원본을 그대로 썼다.
  - **배치 간 분포 이동** : B1의 수명 범위는 534~1,074이고 단수명(<550) 셀이 1개뿐이다. 
  B2는 반대로 짧은 쪽으로 이동해 39셀 중 30셀이 B1 최솟값(534)보다 짧고(평균 566), 
  B3는 긴 쪽으로 이동해 44셀 중 16셀이 B1 최댓값(1,074)보다 길다(평균 1,060, 최대 1,935). 핵심 피처도 B2 44% · B3 48%가 B1 범위 밖이다(KS 검정 p < 1e-5).
  - **다중공선성** : ΔQ 통계끼리 상관 0.92~0.98, VIF는 Min 83 · Mean 46 · Var 24. 
  그래서 ΔQ에서는 수명과 가장 강하고 일관된 **log Var ΔQ** 1개만 대표로 쓰고, log |Min ΔQ| · log |Mean ΔQ|는 거의 같은 정보라 대체재로만 둔다.

## Modeling

### 문제 유형 : Regression 선택 이유
- 550 cycle 기준으로 장/단수명을 나누면 B1이 35 : 1로 치우쳐 분류기를 학습시킬 수 없고, B2는 전부 “단수명”이라고만 찍어도 정확도가 77%라 분류 성능이 의미 없다. 그래서 수명을 숫자로 맞히는 회귀를 택했고 Target은 `log10(cycle_life)`로 변환했다(수명 분포 왜도 1.04 → 0.03).

### 피처 엔지니어링 전략
초기 100 cycle로 계산 가능한 값 22개 후보를 **학습 배치(B1)만으로** 5단계로 걸렀다(사용 가능성 → 측정값 vs 설계 조건 → B1 상관 신뢰구간 → 중복 제거 → 배치 간 부호 확인).

| 구분 | 피처 | 근거 |
|---|---|---|
| 핵심 | log Var ΔQ | 모든 배치에서 수명과 일관된 상관 |
| 보조 | QD(cycle 100) · QD 기울기(2~100) · 충전시간(2~100) | B1에서 유의, 배치 간 방향이 바뀌는 피처는 경고 표시 |
| 대체재 | log \|Min ΔQ\| · log \|Mean ΔQ\| | 핵심과 상관 0.97~0.99 (M3에서만 입력으로 사용, 최종 M2에는 미포함) |
| 제외 | 충전방식 변수, IR, 온도, Skew·Kurt 등 | B1 상관이 우연 수준이거나 배치마다 집합·방향이 다름 |

피처 세트: M1 = 핵심 1개 · **M2 = M1 + 보조 3개 (총 4개, 최종)** · M3 = M1 + M2 + 대체재 2개 (총 6개: log Var ΔQ · QD(100) · QD 기울기 · 충전시간 · log \|Min ΔQ\| · log \|Mean ΔQ\|)

피처 세트별 결과 (SVR, MAPE %)

| 피처 세트 | Train CV | Valid | Valid 20회 반복 | Test B2 | Test B3 |
|---|---|---|---|---|---|
| M1 핵심 1개 | 9.62 | 8.73 | 10.40 ± 2.08 | 30.55 | 11.93 |
| **M2 핵심 + 보조 3개 (최종)** | 8.19 | 4.71 | 6.90 ± 1.54 | 31.45 | 12.45 |
| M3 M2 + 대체재 2개 | 8.27 | 7.12 | 7.62 ± 1.63 | 45.00 | 19.13 |

M2를 고른 근거는 B1 검증(Valid) 최저이다. 새 배치(Batch 2·3)에서는 M1 ≈ M2이고, 핵심과 상관 0.97~0.99인 대체재까지 넣은 M3가 가장 나쁘다(겹치는 정보만 늘어 B1에 더 맞춰짐).

### 모델 선택 및 근거
- 후보 모델 : OLS(M1은 기준선) · Elastic Net · PLS · SVR · GPR · RF · GBM — 모두 회귀, 각각 M1·M2·M3으로 학습(7개 × 3 = 21개 조합)
- 최종 모델 : **SVR (피처 M2)**, `C=10, gamma=0.01, epsilon=0.01`
- 선택 이유 :
  - B1 hold-out(Valid) 4.71%로 전체 1위, 같은 충전방식끼리 묶은 hold-out 20회 반복(6.90 ± 1.54%)에서도 1위. 선택에 테스트 결과는 쓰지 않았다.
  - 평가 방식을 바꿔도(Notion 방식 3개 · 원논문 분할 방식 2개) 5개 평가 중 3개 1위, 나머지도 2위로 상위권.
  - 학습 셀 36개의 소표본이라 단순·정규화 계열이 유리하고, gamma가 작아 거의 직선에 가까운 완만한 곡선이라 DAY 1의 “직선 관계” 결과와 일치. 실제로 SVR 예측은 같은 피처의 직선식으로 95% 설명된다(119셀).
- 검증 : B1을 **같은 충전방식끼리 묶어** 학습 29셀 / hold-out 7셀로 분리, 학습 29셀에서 GroupKFold 5-fold로 튜닝(같은 충전방식 셀이 학습·검증에 나뉘는 누수 방지). 결측 대체·표준화도 학습 데이터로만 fit.

## 오류 분석
- **모델이 가장 크게 틀린 셀의 공통점**
  - Batch 2 : 셀의 92%를 길게 예측(평균 +30.5%). 가장 크게 틀린 셀은 B2c9(791 → 1,341, +70%), B2c44(841 → 1,358, +62%), B2c6(393 → 593, +51%).
  - Batch 3 : 수명 1,600 이상 장수명 셀을 짧게 예측(B3c38 1,935 → 1,067, −45%).
  - 공통점 : 모두 **B1 학습 범위 밖의 셀**이다. 수명이 범위(534~1,074) 밖이거나, 수명은 범위 안이어도 log Var ΔQ가 B1 범위(−4.18~−3.35) 밖이다.
- **원인 가설 및 개선 방향**
  - 같은 ΔQ 값이어도 배치마다 수명 수준이 다르다(배치 차이). 다른 배치 셀 일부를 학습에 포함하면 약 10%까지 줄어든다.
  - 개선: 새 배치 셀 일부 포함, EOL 미도달로 제외한 B1 장수명 셀의 수명 복원으로 학습 수명 범위 확대, 배치 차이를 보정하는 피처 탐색.

## ESS 도메인 해석
- **실제 BESS에 적용한다면 어떤 의사결정에 활용 가능한가?**
  - 같은 생산 로트·운영 조건 안에서는 100 cycle 데이터로 수명을 약 10% 오차로 예측해 셀·모듈별 교체 시점을 미리 계획할 수 있다.
  - ΔQ 분산이 큰 셀을 100 cycle 시점에 단수명 후보로 분류해 집중 관리할 수 있다.
  - 예측이 길게 치우치는 경향(Batch 2)이 있어, 교체 계획에는 예측 수명에서 안전 마진을 빼서 쓴다.
- **어떤 한계가 있으며, 실 배포를 위해 추가로 필요한 것은 무엇인가?**
  - 처음 보는 배치에서는 오차가 크다(Batch 2 31%). 새 로트·새 운영 조건마다 일부 셀을 knee 이후까지 측정해 재학습해야 한다.
  - 학습 셀이 36개이고 그중 단수명이 1개뿐이며, hold-out이 7셀이라 성능 추정이 흔들릴 수 있다.
  - 온도·IR은 측정 신뢰도와 배치별 측정 조건 차이로 사용하지 못했다(원본 데이터 설명).
  - 실제 ESS 운전 패턴(부분 충방전, 휴지, 온도 변화) 데이터로 재검증이 필요하다.
